Instale as extensões do Project Nox

Tenha instalado no seu Android um aplicativo compatível (como Mihon para mangás ou Aniyomi para animes) e siga as instruções abaixo para adicionar gratuitamente nosso catálogo oficial de extensões.

Distribuição oficial 100% gratuita: Utilize os links oficiais do Project Nox. Não é necessário pagar pelo download, instalação ou atualização das nossas extensões.
1. Instalação automática no Android (Recomendado) Um toque

Toque no botão abaixo pelo navegador do celular para abrir o aplicativo diretamente. Se o aplicativo não abrir automaticamente, utilize o método de instalação manual.

Passo a passo no Mihon ou fork

  1. Abra o aplicativo e acesse Mais → Configurações → Navegar.
  2. Entre em Repositórios de extensões e toque em Adicionar.
  3. Cole a URL index.pb (ou um dos formatos JSON caso seu fork exija).
  4. Volte à aba Extensões, atualize a lista e instale as fontes desejadas.

Passo a passo no Aniyomi ou fork

  1. Abra o Aniyomi e vá em Mais → Configurações → Navegar.
  2. Toque em Repositórios de extensões de anime → Adicionar.
  3. Cole a URL index.pb (ou um dos formatos JSON caso seu fork exija).
  4. Atualize a lista de extensões de anime e confie nos pacotes assinados do Project Nox.
Nota técnica sobre compatibilidade: os links automáticos tachiyomi:// e aniyomi:// utilizam index.min.json para compatibilidade com a especificação de deep-link dos aplicativos Android. Nem todos os forks oferecem suporte ao formato index.pb; caso ocorra erro ao adicionar manualmente, utilize index.min.json ou index.json.

Precisa pedir ou reportar uma extensão?

Envie solicitações de novas fontes, relatos de erro, mudanças de domínio ou sugestões diretamente pela central de tickets (requer conta gratuita no GitHub). Para dúvidas rápidas de instalação sem precisar de conta, fale conosco no Discord ou no Fluxer.
