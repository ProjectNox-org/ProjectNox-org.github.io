Instalação dos repositórios de extensões

Adicione os catálogos oficiais do Project Nox no seu aplicativo. Sempre que o aplicativo suportar, utilize o formato Protobuf (index.pb); os índices JSON permanecem sincronizados para compatibilidade com clientes legados.

JSON Compacto (index.min.json) Legado Compacto

Adicionar Automaticamente no Celular (Android)

Como configurar no Mihon ou fork

  1. Abra o aplicativo e acesse Mais → Configurações → Navegar.
  2. Entre em Repositórios de extensões e toque em Adicionar.
  3. Cole a URL index.pb (ou use o botão de adição automática no navegador do Android).
  4. Volte à aba Extensões, atualize a lista e instale as fontes desejadas.

Como configurar no Aniyomi ou fork

  1. Abra o Aniyomi e vá em Mais → Configurações → Navegar.
  2. Toque em Repositórios de extensões de anime → Adicionar.
  3. Cole a URL index.pb (ou toque no botão automático acima no Android).
  4. Atualize a lista de extensões de anime e confie nos APKs assinados do Project Nox.
Nota sobre adição automática: os links tachiyomi:// e aniyomi:// utilizam index.min.json para compatibilidade com a especificação de deep-link dos aplicativos Android. Para colagem manual, dê preferência ao endereço index.pb.
